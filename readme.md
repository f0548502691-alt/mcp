## אפשרות א': אם העברת קובצי התקנה (`.vsix`)

אם מצאת והעברת את הקבצים שהורדו מהדפדפן (למשל `cline.vsix`), ההתקנה מתבצעת ישירות מתוך VS Code במחשב המנותק:

1. פתחי את **VS Code** במחשב המנותק.
2. עברי ללשונית התוספים (Extensions) בסרגל השמאלי (או לחצי על הקיצור `Ctrl + Shift + X`).
3. בראש תפריט התוספים שנפתח, לחצי על תפריט **שלוש הנקודות (`...`)**.
4. תפריט ייפתח – בחרי באפשרות **Install from VSIX...** (התקנה מקובץ VSIX).
5. בחלון שייפתח, נווט לדיסק און קי שלך, בחרי את הקובץ של Cline ולחצי על **Install**.
6. חזרי על הפעולה עבור הקובץ של Copilot.

> 💡 **זהו!** התוספים יותקנו ותופיע הודעה שההתקנה הצליחה. מומלץ לסגור ולפתוח מחדש את VS Code בסיום.
